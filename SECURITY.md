# Güvenlik

Bu repository başlangıç mimarisi ve dokümantasyonu içerir; henüz çalışan platform yoktur.

API key, token, parola, cihaz private key'i veya kişisel audit verisi commit edilmez. Gerçek güvenlik açığı veya secret sızıntısı açık issue üzerinden paylaşılmaz. GitHub repo oluştuğunda private vulnerability reporting ve iletişim yolu belirlenir. Sızan kimlik bilgileri önce iptal edilir/yenilenir.

Platform güvenlik modeli: [docs/security.md](docs/security.md).
